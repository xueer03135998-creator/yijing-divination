# 易经占卜 · 梅花易数 / 小六壬

写下想问的事，给几个数字，页面会排出卦盘，再用大白话把当下局面、中间过程、最后结果和建议讲一遍。梅花易数和小六壬是两套独立的算法，可以随时切换对照着看。

在线使用：https://xueer03135998-creator.github.io/yijing-divination/

这是个纯前端的单文件应用，不依赖服务器，也不要求联网。除非你自己打开大模型解读，所有计算和记录都留在浏览器里。

## 两套占术

梅花易数用数字起卦。填一个到三个 1 到 9 的数字，可以重复，多填了只取前三。只给一个数时按位拆开，给两个数时分别作上卦和下卦，给三个数时第三个数定动爻；动爻还会叠加起卦时的当前时辰做一次微调，所以同一组数字在不同时辰起卦，结果会略有不同。页面把这一步的取数过程写成「起卦依据」，连起卦时间和农历一起显示，方便回头核对。

排盘给出本卦、互卦、变卦，分别对应当下局面、中间过程和最终结果。动爻标出转折发生在哪个阶段，体用关系把你和外部环境的五行生克摆在一起，分成用生体、体克用、体用比和、体生用、用克体几种情形。六十四卦名和六爻爻位都内置在页面里。

小六壬走另一条路。三个数字依次对应月位、日位、时位，加上时辰微调形成四步落点，最后落在大安、留连、速喜、赤口、小吉、空亡六宫之一。四步分别讲起因、过程、你给的数、微调后的终落，比只给一个吉凶更容易看出事情是怎么走过来的。

两个模块的结果区彼此隔离，切换时解读里会留一个入口，可以从一边的结论跳到另一边对照。

## 解读报告

什么都不配置也能用。内置模板会按体用关系或落宫生成一段报告，分一眼结论、现在的情况、中间会怎样、最后的结果、关键提示、给你的建议几段，尽量用日常说法和比方，不堆术语。结果偏凶时也只给可操作的建议，不做宿命论断。

大模型解读是可选的。右上角设置里可以选 DeepSeek、OpenAI、Moonshot（Kimi）、通义千问，或者填一个兼容 OpenAI 格式的自定义地址，再写模型名和 API Key，保存前可以先测试连接，确认接口能不能正常回话。开启后，页面把已经算好的排盘结果连同你问的那件具体事交给模型，要求它只负责用大白话解读，不改卦、不重新取数、不写通稿、不吓唬人，并且严格返回结构化内容。涉及健康、法律、重大资金时，报告里会额外提醒另行咨询专业人士。接口没配好或调用失败时页面会给出提示，关掉开关就能继续用内置模板。

## 记录、账号与分享

第一次打开会让你在本机建一个档案，填昵称和口令，页面里只显示当前档案的算卦记录。侧栏可以新建占卜、回看、删除、清空，也能导出一份备份文件再在别处导入。新建但还没起卦的记录会标成草稿，填好数字点起卦，解读会自动补进这条记录。

查看某条记录后可以生成分享卡片，预览后下载成 PNG，卡片上带占问、类型、时间、卦象或落宫，以及一行免责说明。清空历史记录不可恢复，要留底就用导出备份。

## 数据放在哪里

公开版是本地优先的。档案、登录态、卦例、历史记录和大模型配置都存在你自己浏览器的 localStorage 里，不上传服务器。换浏览器、换设备或清理站点数据后会消失。大模型解读用的 API Key 同样只存本机，浏览器直连第三方接口时可能遇到跨域限制，设置面板里给了用本机反向代理再填自定义地址的办法。

这个公开版本把云同步地址置空了。侧栏里保留的同步状态、立即同步和自动同步开关不会连接任何云端，跨设备搬运记录请走导出备份和导入备份。

传统占术仅供开拓思路，不构成决策依据。每份报告和每张分享卡片都写着这一点，涉及健康、法律、重大资金请另行咨询专业人士。

## 本地打开与仓库内容
