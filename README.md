# 易经占卜 · 梅花易数 / 小六壬

一个本地优先的在线排盘小工具。用数字起卦，结果会随起卦时辰变化，可以切换梅花易数和小六壬，也可以让大模型生成一段解读。

在线使用：https://xueer03135998-creator.github.io/yijing-divination/

## 关于数据

公开版是纯前端单文件，没有后端。昵称、口令、卦例和历史记录都存在你自己的浏览器里，不上传服务器；换浏览器、换设备或清理站点数据后会消失。云同步在这个版本里是关闭的。

大模型解读是可选功能，需要在设置里填自己的接口地址和 API key，密钥同样只存在本机浏览器。不填的话会用内置模板解读，起卦和排盘照常可用。

## 仓库里有什么

`index.html` 是完整应用，样式和脚本都已内联，约 135 KB，没有外部资源依赖，不用装包或跑构建。`.nojekyll` 让 GitHub Pages 跳过 Jekyll 处理。

这个仓库只放构建产物，不含源码。
